# AI Image Brief Safe

Use this before generating images with AI.

## Inputs

- Purpose: thumbnail, Instagram post, product image, illustration, cover.
- Audience.
- Message.
- Required size/aspect ratio.
- Text overlay needs.
- Reference style, if any.

## Workflow

1. Define the message in one sentence.
2. Choose composition, subject, mood, color, and background.
3. Decide whether text should be generated by AI or added later.
4. Add safety constraints.
5. Generate one draft first.
6. Review readability at phone size.

## Output

```
【Image Brief】
Purpose:
Audience:
Main subject:
Composition:
Mood/color:
Text area:
Style:
Avoid:

【Prompt】
xxx

【Review Checklist】
- Readable:
- Not too crowded:
- No broken text:
- No private identity:
```

## Rules

- For Japanese text, prefer textless images and add text later in design software.
- Do not photorealistically copy private people from reference images.
- Keep one main message per image.
- Do not rely on vague "high quality"; specify visual details.
