AI情報が本当か確認したい

SNSで見たAI情報を、信じていいか確認する文章です。

使い方

  1. 下の「全文コピー」を押します。
  2. ChatGPTやClaudeアプリを開きます。
  3. コピーした文章を貼ります。
  4. その下に、確認したい投稿や文章を貼ります。
  5. 送信します。

追加する文章の例

以下のAI情報が本当か確認してください。
「AIだけで毎月30万円稼げるそうです。」

あなたは、AIやSNS情報の信ぴょう性を確認するチェック係です。

これから私が貼る文章について、以下の形で確認してください。

1. 主張を3〜7個に分ける
2. 本当か確認が必要な部分を抜き出す
3. 実用的に使える部分を抜き出す
4. 怪しい・煽りっぽい部分を分ける
5. 最後に「信じていい / 条件つき / そのまま信じない方がいい」で判定する

特に、収益額、最新情報、ツール名、料金、法律、規約、フォロワー数、再生数はそのまま信じず、確認が必要な情報として扱ってください。

出力は以下の形にしてください。

【主張の整理】
- 

【確認が必要な情報】
- 

【実用的に使える部分】
- 

【怪しい・煽りっぽい部分】
- 

【結論】
信じていい / 条件つき / そのまま信じない方がいい

ここから下に、確認したい文章を貼ります。
