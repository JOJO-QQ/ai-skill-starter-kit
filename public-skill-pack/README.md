# AI Practical Skills Starter Pack

This is a safe public version of reusable AI workflow skills.

## Included Skills

- `info-check-lite`: verify SNS/blog/AI claims before using them.
- `api-automation-safety-check`: check risks before browser automation, scraping, or undocumented API work.
- `ai-workspace-design-check`: decide whether to use chat, memory, a reusable skill, a small tool, connector, plugin, or automation.
- `lp-validation-builder`: create a small mobile-friendly landing page plan for a freebie or offer.
- `note-structure-safe`: structure practical note/blog articles.
- `market-research-starter`: validate small digital product or service ideas.
- `instagram-content-safe`: turn episodes or tips into privacy-safe Instagram content.
- `ai-image-brief-safe`: create image-generation briefs without exposing private details.

## What Is Removed

This public pack does not include:

- Personal local paths.
- API keys, cookies, tokens, or billing details.
- Private family/account context.
- Instructions that encourage terms-of-service violations.
- Automation that posts, purchases, reserves, deletes, or sends messages without human confirmation.

## Suggested Use

1. Pick one skill.
2. Paste the skill text into your AI tool.
3. Provide your task.
4. Review the output before using it publicly.

## Smartphone Use

The skills are plain text, so they can be read and pasted from a smartphone. They work well for:

- Checking AI/SNS claims.
- Drafting Instagram posts.
- Planning note articles.
- Creating image-generation briefs.
- Thinking through a small offer.

PC is recommended for:

- Editing files.
- Building landing pages.
- Using Codex/Claude Code.
- Setting API keys or environment variables.
- Testing automations.

## Disclaimer

These skills are practical checklists, not legal, financial, medical, or security advice. For high-risk work, confirm with a qualified professional or the service owner.
